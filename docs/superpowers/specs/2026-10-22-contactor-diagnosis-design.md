# 기존 ESS 링크의 접촉기 진단 시연

- 사용자 요청: 별도 예시 대신 실행 중인 ESS 3D 링크에 적용한다.
- 최종 범위: 하단 `Contactor 진단` 버튼, 선택한 ESS/랙의 하단 BPU 위치 강조와 부드러운 카메라 이동, 부품 옆에 연결선을 가진 밝은 진단 말풍선.
- 사용자는 고정 패널의 디자인을 거부하고 부품에 연결된 말풍선과 이슈 발생 인터랙션을 요청했다. 고정 패널과 내부 설명용 그림은 제거하며, 기존 정보와 상호 배타적으로 표시한다.
- 기본 시연은 RACK 02에서 정상 대기 0.6초 → OPEN 명령 → 1.0초 초과 후 CLOSED 유지에 따른 불일치 판정이다. 버튼을 누르면 자동 시작하고, 다시 발생·정상 비교·일시정지·시간 이동을 제공한다. 랙/ESS 변경은 선택 대상에서 새 시연을 시작한다. 통신 끊김은 근거 펼치기 안에서 시연한다.
- 3D는 실제 모델에 존재하는 BPU 외함까지만 위치를 표시한다. 장난감 형태의 SVG 내부 그림을 제거하고 가상 명령/피드백 신호 그래프를 재생한다. 용착을 확정하지 않는다.
- 모든 신호와 1.0초의 판정 기준은 가상값이다. 통신 끊김은 UNKNOWN/판정 불가로 표시한다.
- 기존 문, 4+2 배치, 공유 모델 재질, 진단 데이터는 유지한다. 소스와 dist를 갱신하여 기존 로컬 서버에서 확인한다. 푸시/배포/ZIP 갱신은 범위 밖이다.
- 성공 기준: 상태·경계 시간 테스트, 빌드, 기존 모델 테스트, 실행 링크에서 랙/컨테이너 전환·닫기·기존 전체 정보·좁은 화면 확인.
