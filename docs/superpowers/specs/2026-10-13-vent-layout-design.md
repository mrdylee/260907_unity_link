# 환기구 대각선 배치

사용자가 최종 확인한 기준은 배터리 문 1·5번 하단, 2·6번 상단에 각 하나씩이다. 가운데 3·4번 문은 제외한다. 총 네 덮개이며 같은 양문의 1–2, 5–6이 대각선 짝으로 열리고 닫힌다.

기존 하단 경첩과 45도 외측 개폐를 유지한다. 하단 버튼은 선택 컨테이너의 네 덮개를 모두 조작한다. 실제 가스 감지나 장비 제어는 추가하지 않는다.

Blender 원본의 기존 네 덮개를 재배치한다. 웹 GLB에서도 같은 계층과 위치를 반영하며 PBR 데이터는 보존한다. 웹에서만 위치를 바꾸면 Blender 원본과 불일치하므로 두 산출물을 함께 갱신한다.

검증: 1·2·5·6번 문당 한 덮개, 3·4번 문 덮개 없음, 홀수 하단·짝수 상단, 같은 양문 쌍만 동작, 아래 축 고정, 45도 외측 개폐, 큰 문 독립, 버튼 전체 개폐, 기존 패널·케이블 검증 통과, 화면 확인.
