# ESS v2 웹 배포 설계
승인 범위: 기존 GitHub 저장소의 Unity/Blender 원본 및 TypeScript 웹 뷰어에 최신 재질 개선본을 반영한다.
기존 Three.js와 문 제어를 유지하고, 검증된 Blender MCP 내보내기 model.json과 베이크 텍스처에서 glTF를 생성한다. Blender를 다시 열어 재수출하는 방법은 불필요한 편집기 상태 변경을 유발하고, Unity WebGL 재구축은 기존 TypeScript 구조를 바꾸므로 사용하지 않는다.
Unity 좌표를 glTF 우수 좌표로 변환하고 노드 이름의 Blender 중복 접미사를 제거한다. Normal 및 Metallic/Smoothness를 glTF Normal 및 Roughness/Metallic으로 변환한다. 원본 저장 파일과 최종 렌더를 포함하고 캐시, 사용자 설정, 임시 로그는 제외한다.
검증: 6랙42팩,8개문, FACP 공동회전, PBR텍스처, 웹 화면, TypeScript 빌드, 포터블 ZIP, 원격 커밋 동일성을 확인한다.
