# 좌측형·우측형 LINK 배치

랙 앞문을 바라보는 기준으로 E-panel 좌측형과 우측형을 구분한다. 사용자가 확인한 4대 배치는 랙 앞문이 두 줄의 바깥을 향하는 2×2이며, 좌우와 앞뒤 외곽 사이 빈 간격은 모두 0.5ft(0.1524m)다. E-panel은 네 대 묶음의 양쪽 바깥에 둔다. 별도 5·6번 쌍도 좌우형을 한 대씩 사용하고, 기존의 4m 그룹 간 임시 통로를 유지한다.

01·02번은 +Z 방향의 랙 앞문과 L/R 타입, 03·04번은 −Z 방향의 랙 앞문과 R/L 타입이다. 05·06번은 +Z 방향의 L/R 타입이다. L/R은 현장 방위가 아닌 각 LINK의 랙 앞문 기준이다.

기존 GLB를 재사용해 오른쪽 타입은 X축을 반전하고, 전면 인쇄 재질의 UV 방향을 보정한다. 별도 GLB 두 벌은 중복 용량이 크며, E-panel만 옮기면 외함·장비실 문이 맞지 않으므로 선택하지 않는다. 원본 지오메트리와 좌측형 재질은 보존한다. 우측형의 세부 배선·기기 배치는 실측 자료가 없는 시각화 목업이며, 실물 우측형 내부를 검증한 결과가 아니다.

확대 카메라는 반전과 회전을 모두 반영한다. 컨테이너/랙 ID와 모의 데이터, 문 제약, Contactor 진단은 그대로 연결한다. 실제 GLB 검사로 두 축 간격, E-panel 외측 위치, 랙 앞문 바깥 방향, 인쇄 재질 격리와 문 개폐 중 외함 간 비관통을 확인하고 실제 페이지에서도 확인한다.

검사 중 기존 100도 장비실 문이 뒤쪽 LINK의 장비실 문·손잡이와 겹치는 것을 실제 메시 OBB로 재현했다. 0.1524m 간격은 유지하고 장비실 문 목업의 개방각을 90도로 제한한다. 이는 시각화 제약이며 실물 힌지의 최대 개방각을 측정한 값이 아니다.

## 검증

- `npm run build`: 통과.
- `ESS_TEST_URL=http://127.0.0.1:3006 npm test`: 실제 GLB 좌우형, 인쇄 재질 격리, 두 축 간격, 앞문 방향, 문 개폐 및 진단 모의 데이터 검사 통과.
- 실제 페이지에서 ESS 02 우측형과 ESS 03 회전된 우측형의 eBSC/LCS 확대, 전체 문 열기, Contactor 이슈 및 정상 비교 확인. 브라우저 오류 로그 없음.
