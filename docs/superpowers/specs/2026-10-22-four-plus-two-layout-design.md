# LINK 4+2 배치

> 이전 배치 기록입니다. 현재 기준은 [좌측형·우측형 LINK 배치](2026-10-23-left-right-link-design.md)입니다. 아래의 짝수 컨테이너 회전과 2m 줄 사이 통로는 더 이상 적용하지 않습니다.

사용자가 2×2 묶음(1·2 / 3·4) + 별도 한 쌍(5·6)을 선택했다. 각 쌍의 외함 사이 빈 간격은 0.5ft = 0.1524m다. 짝수 컨테이너를 Y축으로 180도 회전하여 E-panel은 각 쌍의 바깥 끝을 향한다. 닫힌 모델의 외곽 경계를 기준으로 배치하며 모델 내부나 치수는 수정하지 않는다.

4대 묶음의 두 줄 사이는 목업 기준 2m 통로, 4대 묶음과 2대 묶음 사이는 4m로 둔다. 이 두 통로 폭은 현장 실측 지정값이 아닌 가시성과 문 개방 공간을 위한 임시 배치값이다.

`src/ContainerLayout.ts`가 여섯 외곽 상자의 위치·회전을 정하고 전체 경계를 반환한다. `src/main.ts`는 이를 사용하고 전체 카메라를 배치에 맞추며, 모든 상세 카메라 위치·방향에 선택한 컨테이너의 회전을 반영한다. 그룹 구분선과 4대/2대 라벨은 전체 보기에서만 보인다. 컨테이너 번호, 랙·장치 ID, 모의 데이터, 문 동작은 유지한다.

실제 GLB를 복제한 검사에서 세 쌍의 간격, 두 그룹, 반대 방향, E-panel 바깥 방향, 모든 문 개방 중 컨테이너 경계 비관통을 확인한다. UI에서는 전체 배치와 짝수 컨테이너의 랙·패널 확대, 선택 데이터 전환을 확인한다.
