# 랙 이웃 문 개방각 확대

사용자가 RACK 2·3 사이 문을 더 넓게 열도록 요청했다. 현재 GLB는 이웃 문 2/3 및 4/5가 동시에 열릴 때 앞쪽 테두리가 먼저 맞닿아 약 59.2166도에서 멈춘다. 충돌 검사를 제거하면 실제 문·손잡이가 겹친다.

테두리의 돌출 깊이를 15mm 줄이는 방식을 선택한다. 해당 네 문의 `Door_Edge_*` 16개만 로컬 Z 방향으로 −0.015m 이동한다. 외함 크기, 랙, 패널, 손잡이, 경첩과 회전축은 유지한다. 같은 로직으로 약 81.2223도까지 열린 뒤 손잡이 간섭 전에 멈추는 것을 메모리상 실제 GLB 시험으로 확인했다. 20mm 보정은 추가 각도 이득이 없어 선택하지 않는다.

변경은 웹 GLB에 저장한다. Blender MCP에 연결할 수 없어 `.blend`는 변경하지 않으며, 이후 재내보내기 시 동일 변환 스크립트를 적용해야 한다. 실제 기구 설계나 실물 개방각을 확정한 것이 아닌 시각화 모델 조정이다.

회귀 기준은 이웃 문 동시·순차 개방 모두 80도 초과, 양 방향 개폐 및 반전/회전 LINK에서 메시 비관통, 기존 0.1524m 간격 보존이다. 실행 빌드와 ZIP, C#·프런트엔드 가이드도 현재 모델 기준으로 갱신한다.

검증 결과: 기존 자산에서 59.2166도 실패를 재현했고, 수정 후 전체 빌드·테스트가 통과했다. GLB JSON은 해당 16개 위치의 Z만 바뀌었으며 mesh/texture 바이너리 chunk는 동일하다. 변환 재실행은 바이트를 바꾸지 않는다. 실제 페이지에서 [수정 전](../../images/rack-doors-before.jpg)과 [수정 후](../../images/rack-doors-after.jpg) 열림 상태를 확인했다.
